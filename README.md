# BioSecBench-RespiratoryVirus-Surveillance

**Benchmarking respiratory virus surveillance**

Tests whether AI agents can analyze laboratory results, genetic data, and health records to identify respiratory viruses, check how well diagnostic tests work, and track how these viruses change and spread. These capabilities support public-health efforts to spot outbreaks and estimate how many people are getting sick. Scores show the share of attempts that reach the correct answer, counting refusals and errors as failures. A higher score means the model is more accurate at these tasks.

This is the second biosecurity benchmark that deals with surveillance, with this one isolating capabilities in specific respiratory viruses outbreak scenarios. 

In this repo, there are 3 public tasks that DO NOT APPEAR in the benchmark, but mimic benchmark like questions.
